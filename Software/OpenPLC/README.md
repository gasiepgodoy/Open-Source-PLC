# Open-Source-PLC - OpenPLC

To validate the project using OpenPLC and the IEC 61131-3 languages, a test scenario was created in the UNESP Sorocaba laboratory using a station for separating parts by color.

The test consists of controlling the station by separating the parts and sending data to an online dashboard via MQTT. The files can be found in the "Project Jaguar MQTT" folder and a video demonstrating how it works is available at: https://youtu.be/A4_A6H7zyto
